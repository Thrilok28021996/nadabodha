# Nadabodha

A macOS app for recording or importing audio and transcribing it locally on the Mac.

## V1 direction

- Record audio with the microphone or import an audio file.
- Run speech-to-text on-device; do not upload audio to a transcription service.
- Display the resulting transcript and allow copying or saving it as plain text.

The implementation plan and supported formats will be documented as the app is built. No cloud transcription, accounts, or sync are in scope for v1.
